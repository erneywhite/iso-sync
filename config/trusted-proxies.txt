# Доверенные прокси — чьему заголовку X-Forwarded-For можно верить.
#
# Пусто (всё закомментировано) = не доверяем никому, заголовок игнорируется,
# клиент определяется строго по REMOTE_ADDR. Это безопасный дефолт.
#
# Раскомментируй, если сайт работает в связке nginx + Apache (частый режим
# aaPanel): тогда PHP крутится под Apache, видит соединение с петли, а твой
# настоящий адрес приезжает в заголовке от nginx.
#
# Проверить, нужно ли это: открой /whoami.php — если REMOTE_ADDR показывает
# 127.0.0.1 или адрес docker-сети, а в X-Forwarded-For твой настоящий IP,
# то нужно.
#
# ВАЖНО: сюда вписываются адреса ПРОКСИ, а не твои. Доверять можно только
# тому, до кого снаружи не достучаться напрямую — иначе кто угодно подставит
# заголовок и увидит приватный листинг. Убедись, что бэкенд-порт Apache
# (обычно 8181) закрыт снаружи:
#     ss -tlnp | grep 8181       # должен слушать 127.0.0.1, а не 0.0.0.0
#
# Более чистое решение — починить на уровне веб-сервера, тогда этот файл не
# нужен вовсе (см. docs/PRIVATE-DIRS.md, раздел «nginx + Apache»).

#127.0.0.1
#::1
